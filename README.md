# בתי ספר בלוד

מדריך משפחתי בעברית על בסיס Next.js App Router, TypeScript ו-Tailwind CSS.

```bash
npm install
npm run dev
```

כל בתי הספר והנתונים נמצאים ב-[`src/data/schools.ts`](src/data/schools.ts). רשימת הבסיס והכתובות מתוך [עיריית לוד](https://www.lod.muni.il/he/264/), ובתי ספר נוספים מתוך [אזורי הרישום](https://www.lod.muni.il/he/263/). אין למלא שדות חסרים ללא מקור ושנת מדידה. נתוני תלמידים, כיתות והשוואות ראמ״ה ל־2023–2024 מוצגים דרך [GoInfo](https://goinfo.co.il/education/lod/), שמפנה לנתוני משרד החינוך וראמ״ה. השכבות ושנות המדידה נרשמות לצד כל מדד.

זמני הליכה ונסיעה בטווחים מופיעים בשבעה בתי ספר. אלה אומדנים גסים המבוססים על מיקום הרחוב ב־OpenStreetMap, מקדם מסלול ומהירות ממוצעת; לא נבדק מסלול בפועל ואין נתוני עומס. נקודת המוצא מוצגת בשם הרחוב והמספר לבקשת בעלי האתר. קואורדינטות הבית אינן נשמרות בקוד. מרחק מסלולי נגזר מאמצע אומדן זמן ההליכה במהירות 4.8 קמ״ש; מרחק אווירי נגזר מיחס מסלול 1.3. אלה אומדנים גסים ולא מסלול ניווט או מדידת GPS. בתי ספר בלי בסיס סביר לאומדן מציגים חוסר נתון.

## ממשק ונתונים

לחיצה על מסנן זרם מציגה הגדרה קצרה וקישור למסמך משרד החינוך. גופני Rubik ו־Secular One נטענים מ־Google Fonts. במסך בית הספר מופיעים פרטי קשר כאשר נמצאו ברשימת העירייה. מדדים כגון מספר תלמידים, גודל כיתה, הישגים ואקלים נותרים ריקים עד לאימות מקור ושנה.

## הרחבת התוכן

גם תחקיר האירועים, תיאורי האוכלוסייה, השנים והקישורים למקורות נערכים בקובץ היחיד [`src/data/schools.ts`](src/data/schools.ts), בחלק `research`. הממשק מציג את הנתונים בתוך האתר וקישור המקור מופיע ליד כל אירוע ובתחתית הפרופיל. היעדר אירוע מתועד בסקירה אינו הוכחה שלא התרחש אירוע. אין להוסיף טענות על אלימות או על קטינים מתוך פוסט יחיד או בלי אימות מספק.

תוויות שפת האם הן השוואה יחסית של ראמ״ה לבתי ספר דומים, לפי שכבה ושנה. באתר אין ממוצע ציונים מספרי מאומת לכל מוסד ולכן אין ציון מומצא. שיוך לזרם אינו מידע על זהות התלמידים; השתתפות במפגשים בין מוסדות נרשמת בנפרד מלימוד משותף באותו בית ספר. כיתות הלימוד בכרטיסים לקוחות מנתוני 2024, ובמקרה של הראל מוצגת במפורש אי התאמה בין רישומי העירייה והמאגר.
