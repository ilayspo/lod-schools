# בתי ספר יסודיים בלוד

אתר עצמאי בעברית וב־RTL, המבוסס על Next.js App Router, React, TypeScript ו־Tailwind CSS. מותאם קודם כל לטלפון.

```bash
npm install
npm run dev
```

## נתונים

כל נתוני בתי הספר, השנים, המקורות, התחקיר והמיקומים מרוכזים בקובץ אחד: [`src/data/schools.ts`](src/data/schools.ts). הרשימה והכתובות מבוססות על [עיריית לוד](https://www.lod.muni.il/he/264/), [אזורי הרישום](https://www.lod.muni.il/he/263/) ומקורות בתי הספר. מספר התלמידים, הכיתות, הממוצעים וההשוואות מוצגים עם שנות המדידה, מתוך משרד החינוך וראמ״ה כפי שמופיעים ב־[GoInfo](https://goinfo.co.il/education/lod/). שדה חסר מוצג ככזה.

מיקומי בתי הספר במפה לקוחים מ[מאגר קואורדינטות שערי הכניסה של משרד החינוך](https://data.gov.il/he/datasets/ministry_of_education/coordinates), לפי סמל מוסד. רמת הדיוק הרשומה בהם גבוהה או גבוהה מאוד. הבית בבעל התניא 1 סומן לפי [בניין הכתובת ב־OpenStreetMap](https://www.openstreetmap.org/way/860709523). המפה משתמשת ב־Leaflet ובאריחי OpenStreetMap עם ייחוס גלוי. אין באתר חישוב מרחקים או מסלולים.

## ממשק

מסך בתי הספר כולל חיפוש, סינון לפי סוג חינוך, מספר תלמידים וממוצע תלמידים בכיתה. מסך המפה מציג את לוד, את נקודת הבית ואת כל 13 בתי הספר; לחיצה על סמן או שם ברשימה פותחת את פרטי בית הספר באותו אתר. ההסברים על זרמי החינוך, נתוני ראמ״ה, אירועים מתוארכים והרכב אוכלוסייה מוצגים לצד המקורות.

תוויות שפת האם הן השוואה יחסית של ראמ״ה לפי שכבה ושנה; אין ציון מספרי מאומת לכל מוסד. שיוך לזרם אינו מעיד על הרכב התלמידים, ומפגשים בין מוסדות אינם שקולים ללימוד משותף באותו בית ספר. היעדר אירוע מתועד בסקירה אינו הוכחה שלא התרחש אירוע.
