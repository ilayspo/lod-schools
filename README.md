# בתי ספר בלוד

מדריך משפחתי בעברית על בסיס Next.js App Router, TypeScript ו-Tailwind CSS.

```bash
npm install
npm run dev
```

כל בתי הספר והנתונים נמצאים ב-[`src/data/schools.ts`](src/data/schools.ts). רשימת הבסיס והכתובות מתוך [עיריית לוד](https://www.lod.muni.il/he/264/), ובתי ספר נוספים מתוך [אזורי הרישום](https://www.lod.muni.il/he/263/). אין למלא שדות חסרים ללא מקור ושנת מדידה. נתוני ראמ״ה יתווספו רק אחרי בדיקה פרטנית ב-[מצב החינוך](https://outcomes.edu.gov.il/).

זמני הליכה ונסיעה בטווחים מופיעים בשבעה בתי ספר. אלה אומדנים גסים המבוססים על מיקום הרחוב ב־OpenStreetMap, מקדם מסלול ומהירות ממוצעת; לא נבדק מסלול בפועל ואין נתוני עומס. כתובת הבית והקואורדינטות שלו אינן נשמרות בקוד הציבורי. בתי ספר בלי בסיס סביר לאומדן מציגים חוסר נתון.

## ממשק ונתונים

לחיצה על מסנן זרם מציגה הגדרה קצרה וקישור למסמך משרד החינוך. גופני Rubik ו־Secular One נטענים מ־Google Fonts. במסך בית הספר מופיעים פרטי קשר כאשר נמצאו ברשימת העירייה. מדדים כגון מספר תלמידים, גודל כיתה, הישגים ואקלים נותרים ריקים עד לאימות מקור ושנה.
