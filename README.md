# סקירת בתי ספר יסודיים בלוד והסביבה

אתר עצמאי בעברית וב־RTL, מותאם לטלפון. בנוי ב־Next.js App Router, React, TypeScript, Tailwind CSS ו־Leaflet. הפעלה מקומית: `npm install` ואז `npm run dev`.

## עדכון נתונים

כל בתי הספר נמצאים ב־[`src/data/schools.ts`](src/data/schools.ts). הרשימה כוללת 13 בלוד, 15 ברמלה ו־10 בבאר יעקב. לכל מוסד שם, עיר, זרם, כתובת ושכבות כשהן ידועות, סמל מוסד, נתוני תלמידים וכיתות לשנת 2024 כשנמצאו, ומקורות. רשימות העיריות: [לוד](https://www.lod.muni.il/he/264/), [רמלה](https://ramle.org.il/0-1672323258-%D7%A8%D7%A9%D7%99%D7%9E%D7%AA-%D7%91%D7%AA%D7%99-%D7%A1%D7%A4%D7%A8/) ו[באר יעקב](https://www.b-y.org.il/duplicated-1704189061/). נתוני 2024 הם ממשרד החינוך כפי שמוצגים ב־GoInfo; הנתון ״תלמידים בכיתה״ הוא השדה המדווח, ואינו מחושב כאן מחדש מחלוקת תלמידים בכיתות.

ת״ת בר אילן–רזיאל מופיע ברשימת העירייה, אך לא נמצא לו נתון מספרי תואם במקור 2024. שדות חסרים מוצגים כ״אין נתון זמין״. במדדי ראמ״ה נשמרות שנת המדידה והשכבה כשנמצאו.

## מפה ורישום מחוץ לעיר

המפה מציגה סמן רק כשהמיקום אומת. מיקומי לוד נלקחו מ[מאגר קואורדינטות משרד החינוך](https://data.gov.il/he/datasets/ministry_of_education/coordinates); שאר בתי הספר נשארים נגישים ברשימת המפה עד אימות נקודה מדויקת. נקודת הבית בלוד מוצגת ללא חישוב מרחק או מסלול. האריחים הם של OpenStreetMap.

אפשר להגיש בקשה ללימודי חוץ, בכפוף לאישור רשות המגורים והרשות הקולטת. הקבלה אינה מובטחת וייתכן חיוב באגרה לפי נסיבות ההעברה. ראו [הנחיות רמלה](https://ramle.org.il/892/) ו[טופס באר יעקב](https://www.b-y.org.il/927/).
